# 시선의 힘 · 수정본

`eye_tracking_demo.html`은 외부 빌드 도구 없이 실행하는 단일 HTML 앱입니다. Chrome 또는 Edge에서 열어 카메라 권한을 허용합니다. 카메라 접근이 제한되면 HTTPS 또는 localhost에서 실행합니다. 첫 실행에는 MediaPipe 파일 다운로드를 위한 인터넷 연결이 필요합니다.

## 체험

1. 전체 화면을 사용할 경우 보정 전에 먼저 켭니다.
2. 카메라는 화면 위 중앙에 두고, 얼굴에 빛이 고르게 닿도록 앉습니다.
3. 얼굴이 안정되면 9점 보정과 별도의 5점 검증을 진행합니다. 검증 오차가 크면 게임을 시작하지 않습니다.
4. 중앙 고정 모드로 먼저 확인합니다. 이동 모드는 시작 10초 뒤부터 천천히 움직입니다.
5. 화면 크기나 앉은 위치가 바뀌면 다시 보정합니다.

## 동작

- 홍채 좌표를 눈의 로컬 축과 눈 너비로 정규화합니다. 눈꺼풀 간격은 눈 감김 판별에만 사용합니다.
- 보정점마다 눈 좌표의 중앙값을 구하고, 실제 화면 좌표를 대상으로 가로·세로 선형 회귀를 적용합니다. 얼굴 자세는 유효성 판정에만 사용해 고개 움직임을 시선으로 학습하지 않습니다.
- 각 점에서 1초 대기 후 1.4초 이상 수집합니다. 게임과 동일한 필터로 검증하며, 오차가 크면 첫 검증 데이터로 한 번 추가 보정하고 새로운 5점 측정으로 재검증합니다. 통과 기준은 그대로 유지합니다.
- 실패 화면에 가로·세로 오차를 픽셀로 표시하고, 운영자 진단에도 실패 보고서를 남깁니다. 실제 정확도가 개선됐다는 의미는 아니며, 실제 카메라에서 다시 확인해야 합니다.
- 70ms 시정수의 시간 기반 필터를 사용합니다. 카메라 프레임 수에 비례하는 벌점을 없앴습니다.
- 0.5초 이하의 타겟 이탈은 벌점 없이 유예합니다. 이후 초당 에너지 12를 차감합니다.
- 눈 감김, 얼굴 이탈, 복수 얼굴, 자세 변화, 오래된 추정값에서는 시간과 채점을 멈춥니다. 인식이 안정되면 재개하며, 20초 이상 복구되지 않으면 체험을 종료합니다.
- 영상과 보정값은 메모리에만 유지합니다. 영상 저장, 서버 전송, 분석 SDK는 없습니다.

## 검증과 한계

`node verify.cjs`로 회귀, 보정 실패, 깜빡임, 추적 실패, 일시정지 복귀, 프레임 속도별 벌점, 재시작, 리사이즈를 확인합니다.

`node browser-check.cjs`는 이 PC의 Playwright 캐시에 있는 숨겨진 Chromium과 가상 카메라로 검사합니다. npm 의존성은 없으며, 실행 파일 경로는 다른 PC에서 변경해야 합니다. 실제 CDN 모델 로딩을 확인하고, 합성 홍채 입력으로 보정부터 게임 종료 및 재시작까지 검증하며 PNG를 저장합니다.

자동 검증은 실제 사람의 시선 정확도를 측정하지 않습니다. 보정 검증 임계값과 판정 반경은 체험을 위한 초기 설정이며, 박람회에서 사용할 카메라·모니터·조명 및 안경 착용 여부를 포함한 실측으로 조정해야 합니다. 타겟 유지율은 게임 지표이고 집중력 검사가 아닙니다.
